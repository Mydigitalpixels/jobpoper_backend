# JobPoper Admin Panel

React admin panel for the JobPoper backend.

## Run locally

1. Install frontend packages:
   `npm install`
2. Start the React app:
   `npm run dev`

The Vite dev server proxies `/api` and `/uploads` to `http://localhost:3001`.

## Build

`npm run build`

After build, the backend serves the panel from `/admin` when `admin-panel/dist` exists.
